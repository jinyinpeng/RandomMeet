# RandomMeet — 随机视频 / 语音聊天 MVP

这是一个早期测试版，使用 Node.js、Express、Socket.IO 和 WebRTC。网页支持桌面与移动浏览器；需要 HTTPS、浏览器媒体权限和可用的网络连接。

## 当前已实现

- 响应式网页界面。
- 视频聊天与纯语音聊天。
- 按聊天模式进行随机排队与匹配。
- 跳过、挂断和对方离开后的清理。
- WebRTC offer/answer 与 ICE 候选交换；前端会缓存远端描述到达前的 ICE 候选。
- `/health` 健康检查。
- 基础 HTTP 安全响应头、Socket.IO 单消息大小上限、信令字段/大小校验、会话 ID 强校验，以及按连接的轻量事件频率限制。
- 隐私说明与安全守则页面。

## 当前限制（请在公开推广前处理）

- **TURN 中继需外部配置**：代码已支持通过 `/ice-config` 发放短期 TURN 凭据，但当前 Render 尚未配置 TURN 服务及密钥；在配置前仍只使用 STUN。部分 NAT、运营商、公司/学校网络或防火墙环境下，连接可能失败。
- **举报未落库**：举报按钮只显示说明，不会保存案件、通知审核人员或触发封禁。
- **没有真正的屏蔽功能**：用户不能可靠地屏蔽某个对象或阻止再次匹配。
- **没有人工审核后台**：没有案件队列、审核工具、申诉流程或响应时限。
- **没有年龄验证或充分的滥用防护**：仅有按单个 Socket 连接计算的轻量事件频率限制；尚未实现可靠年龄验证、IP/账号级限流、反机器人或系统化滥用监测。
- **匹配状态是内存状态**：队列和配对信息保存在单个服务进程内；重启会清空。当前不支持跨实例协调。
- **没有用户资料筛选**：当前只按视频/语音模式匹配，不支持性别、国家/地区筛选。
- **隐私与合规仍需完善**：尚未进行独立安全审计、渗透测试或适用法律（包括可能适用的 GDPR）审查。

## 本地运行

需要 Node.js 20 或更新版本。

```sh
npm install
npm start
```

然后打开 `http://localhost:3000`。摄像头/麦克风权限通常需要 HTTPS 或 localhost。

## 环境变量

- `PORT`：监听端口，默认 `3000`。
- `STUN_URLS`：可选，逗号分隔的 STUN URL；默认使用 Google 公共 STUN。
- `TURN_URLS`：可选，逗号分隔的 TURN/TURNS URL。
- `TURN_SHARED_SECRET`：可选，coturn REST API 共享密钥；仅保存在 Render 环境变量中，不能放入前端或 Git 仓库。
- `TURN_TTL_SECONDS`：可选，临时 TURN 凭据有效期，默认 3600 秒，服务端限制为 300–86400 秒。

配置了 `TURN_URLS` 与 `TURN_SHARED_SECRET` 后，`/ice-config` 会为客户端生成带有效期的临时凭据；未配置时继续使用 STUN。TURN 服务本身需另行提供并正确配置 coturn REST 认证。

## 部署与安全提醒

- 使用支持 Node.js、WebSocket 和 HTTPS 的平台部署。
- 生产环境配置 TURN；不要把长期 TURN 密码写入公开前端代码。
- 正式开放前补齐举报存储、人工审核、屏蔽、速率限制、年龄保护、隐私联系渠道和数据保留/删除流程。
- 明确说明媒体连接方式及其隐私边界。即使服务端不主动录制，通话另一端也可能使用外部设备录制。
- 公开运营前请确认适用的平台规则、当地法律与数据保护义务。

**重要：RandomMeet 目前只是测试版，不是具有完整审核和安全保障的正式社交平台。请勿向用户承诺尚未实现的安全功能。**
