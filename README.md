# RandomMeet — 随机视频 / 语音聊天 MVP

这是一个可本地运行的全栈原型，使用 Node.js、Express、Socket.IO 和 WebRTC。UI 支持 iPhone Safari 与桌面浏览器的响应式布局。

## 实现状态

### 已实现（MVP 源码内）
- 响应式网页界面，适配手机与电脑。
- 视频模式与纯语音模式（浏览器媒体授权 + WebRTC）。
- 随机排队与匹配；按用户自报性别、国家/地区，以及双方选择的聊天模式筛选。
- 跳过、挂断、举报、屏蔽当前会话。
- 健康检查 `/health`。
- 举报记录尝试追加到 `reports.jsonl`。
- 基本安全响应头、隐私说明与安全守则页面。

### 尚不适合正式公开运营
- **TURN 中继服务器**：当前只配置 STUN。不同 NAT、运营商和企业网络环境下，WebRTC 可能连接失败。生产环境建议配置 coturn 或托管 TURN 服务。
- **持久化匹配与用户屏蔽**：匹配队列、资料和屏蔽列表目前都在内存中；重启会丢失。
- **人工审核与举报后台**：当前只保存举报日志，没有管理后台、自动封禁、人工审核或举报通知。
- **年龄验证、滥用防护与速率限制**：尚未实现正式年龄验证、反机器人、IP/账号速率限制。
- **生产级安全与隐私合规**：尚未进行独立安全审计、渗透测试或 GDPR 等适用法律审查。
- **女性筛选的现实限制**：平台只依据用户自愿填写的资料，不验证真实性，也不能保证任何时刻都有符合条件的在线用户。

## 运行要求
- Node.js 20 或更新版本
- npm

## 本地运行
1. 解压项目。
2. 在项目目录打开终端。
3. 执行 `npm install`，再执行 `npm start`。
4. 在浏览器打开 `http://localhost:3000`。

## 环境变量
- `PORT`：监听端口，默认 `3000`
- `REPORT_FILE`：举报日志文件路径，默认项目目录中的 `reports.jsonl`

## 部署注意
- 通过支持 Node.js 与 WebSocket 的平台部署，并使用 HTTPS。
- 生产环境需配置 TURN 服务，且不要把长期 TURN 密码写进公开前端代码。
- 配置持久化数据库、举报管理后台、访问控制、速率限制和日志轮换。
- 补齐隐私政策、服务条款、年龄保护和用户举报处理流程。
- 在公开上线前确认平台规则、当地法律、数据保护义务及内容审核能力。

本项目是早期 MVP，不应被视为已完成安全审核的正式社交平台。媒体流由浏览器获取，WebRTC 尝试在客户端之间直接传输；对端仍可能通过外部设备录制画面。
